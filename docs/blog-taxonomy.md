# ブログ記事の分類を選ぶ

NotionのブログDBで、カテゴリー・記事形式・トピックを分けて設定します。カテゴリーは読者が探す棚、記事形式は書き方、トピックは具体的な話題です。

## カテゴリーは記事を探す棚を1つ選ぶ

| カテゴリー         | 扱う内容                                                             |
| ------------------ | -------------------------------------------------------------------- |
| 本の感想           | 本の感想、読書メモ、読書の振り返り                                   |
| 日記               | 日々の出来事、活動の振り返り                                         |
| 技術               | 実装、設計、セキュリティ、運用、技術選定                             |
| 組織・マネジメント | 人事評価、チームづくり、リーダーシップ、キャリア、開発の進め方       |
| プロダクト         | 顧客価値、企画、意思決定、デザイン、マーケティング、ユーザーリサーチ |
| 投資               | 決算、企業、銘柄、財務分析                                           |

本について書いた記事は内容にかかわらず「本の感想」、日々の記録や活動の振り返りは「日記」を優先します。そのほかの記事は主題に合う棚を選びます。本の話題が人事評価や技術でも、具体的な内容はトピックで補えます。「暮らし・教養」は使いません。

## 記事形式は書き方を1つ選ぶ

| 記事形式       | 判断の基準                         |
| -------------- | ---------------------------------- |
| 読書メモ       | 本の感想、学び、読書ノート         |
| Podcastメモ    | 音声番組を起点にした学びや考察     |
| 技術メモ       | 実装、設定、調査、手順の記録       |
| 考察           | 自分の問いや主張を軸にした文章     |
| 日記           | 日々の出来事の記録                 |
| 振り返り       | 一定期間の活動や読書を振り返る文章 |
| 決算分析       | 特定の決算を読む記事               |
| 銘柄分析       | 企業や銘柄の総合分析               |
| 動画・登壇メモ | 動画や発表を起点にした学びの記録   |
| 資料・ガイド   | あとから参照するための説明や案内   |

AIを使ったかどうかは記事の主題と別です。旧TagsのGPTを、そのままAIのトピックに移しません。

## トピックは具体的な話題を選ぶ

Go、GCP、Figma、スクラム、人事評価など、記事に実際に出てくる具体的な話題を設定します。必要に応じて複数選べます。既存の名称を優先し、同じ意味の表記を増やさないようにします。カテゴリーや記事形式をそのまま重複して入れる必要はありません。

| 記事                             | カテゴリー | 記事形式 | トピックの例           |
| -------------------------------- | ---------- | -------- | ---------------------- |
| 人事評価の本の感想               | 本の感想   | 読書メモ | 人事評価               |
| GoのCLIを定期実行する方法        | 技術       | 技術メモ | Go、GCP                |
| Figmaの決算分析                  | 投資       | 決算分析 | Figma                  |
| プロダクトマネージャーの本の感想 | 本の感想   | 読書メモ | プロダクトマネジメント |
| 日々の出来事                     | 日記       | 日記     | 必要に応じて設定       |

## ブログの入口と旧URL

ブログのナビゲーションはカテゴリーを使います。メニューには記事形式から探す入口も用意し、記事ページのトピックから関連する記事へ移動できます。検索は新しい分類と旧Tagsの両方を対象にします。

カード・記事ヘッダー・OGPでは「本の感想 / 読書メモ」「日記 / 日記」の重複表示を省きます。記事形式の値はNotionに保持し、形式別の一覧と検索では引き続き使えます。

- カテゴリー：`/posts/category/<名前>`
- 記事形式：`/posts/format/<名前>`
- トピック：`/posts/topic/<名前>`
- 旧タグ：`/posts/tag/<名前>`

同じ分類のページ送りは `/page/<番号>` を付けます。新しい3種類の一覧にも、それぞれの名前を表示するOGPを生成します。

旧Tagsは分類の履歴と既存URLのために残します。新しく記事を書くときは新しい3項目を使い、旧Tagsを設定する必要はありません。分類が未設定の記事も表示できますが、カテゴリー・記事形式の一覧には入りません。

## 移行の記録

2026年10月10日に、公開42件とタイトルのある下書き29件を分類しました。無題の1件は分類を付けていません。公開状態、本文、記事URL用のSlug、既存のTagsは維持しています。Notionの既定ビューでは新しい3項目を表示し、カテゴリーと記事形式を絞り込めるようにしました。

分類案と移行前のプロパティの控えは、作業用ワークスペースの `output/primer-redesign/notion-taxonomy-*.json` に保存しています。下書きを含むため、リポジトリには含めません。

移行後、Notionの全72行を読み直し、71件の分類と既存プロパティの保持を確認しました。その後、書き手の希望に合わせて「本の感想」「日記」を独立したカテゴリーにし、45件のカテゴリーを変更しました。公開記事の内訳は本の感想23件、日記7件、組織・マネジメント6件、技術4件、プロダクト1件、投資1件です。

再ビルドでは133ページと1200×630のOGP画像125枚を生成しました。全61種類の分類一覧で公開42件の割り当てが一致し、旧URL・画像・ページ送りにリンク切れがないことを確認しています。ブラウザーでも修正後のメニューと「本の感想」の2ページ目を確認しました。
